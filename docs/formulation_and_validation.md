# Direct Time-Domain Grounded-Wire TDEM/IP Formulation

This note is the implementation contract for the current ATEM3D prototype.  It
keeps the source, IP coupling, boundary treatment, and empymod validation
conventions explicit so future changes can be checked against equations instead
of memory.

## Continuous Equations

The quasi-static Maxwell equations used here are

```text
curl e + d b / dt = - d s_m / dt
curl h - j_c = s_e
b = mu h
```

For the grounded wire source used in the examples, `s_m = 0` and the impressed
electric source `s_e` is a line-current density supported on the wire path.  A
step-off source is represented as

```text
s_e(t) = I(t) q_e
I(t < 0) = I0
I(t >= 0) = 0
```

where `q_e` is the finite-volume edge projection of the wire.  The initial
on-time state is a DC galvanic field plus a static magnetic field generated by
the total current system.

## Debye IP Coupling

The code uses a conductivity-form Debye expansion:

```text
j_c(t) = sigma_inf e(t) - sum_i delta_sigma_i y_i(t)
tau_i d y_i / dt + y_i = e
```

`sigma_inf` is the high-frequency conductivity and
`sigma_0 = sigma_inf - sum_i delta_sigma_i` is the low-frequency conductivity.
Physical input must satisfy `sigma_0 > 0`.

With backward Euler over `dt_n = t_{n+1} - t_n`,

```text
y_i^{n+1} = alpha_i y_i^n + beta_i e^{n+1}
alpha_i = tau_i / (tau_i + dt_n)
beta_i = dt_n / (tau_i + dt_n)
```

so

```text
j_c^{n+1}
  = (sigma_inf - sum_i beta_i delta_sigma_i) e^{n+1}
    - sum_i alpha_i delta_sigma_i y_i^n
```

The finite-volume EB system is therefore

```text
(b^{n+1} - b^n)/dt_n + C e^{n+1} = 0
C^T M_mu^-1 b^{n+1} = M(j_c^{n+1}) + s_e^{n+1}
```

Eliminating `b^{n+1}` and the Debye memories gives the magnetic-history edge
solve

```text
[C^T M_mu^-1 C + (1/dt_n) M_sigma_eff] e^{n+1}
  = (1/dt_n) C^T M_mu^-1 b^n
    + (1/dt_n) sum_i alpha_i M_delta_sigma_i y_i^n
    - (1/dt_n) s_e^{n+1}

sigma_eff = sigma_inf - sum_i beta_i delta_sigma_i
```

For non-CPML runs the implementation uses the algebraically equivalent
source-difference/history form instead:

```text
[C^T M_mu^-1 C + (1/dt_n) M_sigma_eff] e^{n+1}
  = (1/dt_n) [M_sigma_inf e^n
      - sum_i beta_i M_delta_sigma_i y_i^n
      - (s_e^{n+1} - s_e^n)]
```

At the first sample after an ideal step-off, `s_e^n` is the left-limit
`s_e(0^-)` and `s_e^{n+1}` is normally zero.  This source-difference form makes
the electric solve depend on the electric/source history, not on a diagnostic
magnetic initial field.  If `b^n` satisfies the previous Ampere balance the two
RHS forms are identical.  If `b^n` does not satisfy that balance, the direct
`b^n` form injects the Ampere residual as a spurious source term, while the
source-difference form leaves the residual in the stored magnetic field.  Active
CPML still uses the magnetic-history form because the split-curl PML memories are
derived from the stretched Faraday/Ampere pair.

## Initial Fields

The initial electric field is computed from the DC scalar-potential problem

```text
G^T M_sigma0 G phi = G^T s_e(0^-)
e0 = -G phi
```

with one scalar-potential gauge node fixed.  The default `initial_magnetic_field:
ampere` route computes a static magnetic flux `b0` from a discrete
vector-potential solve satisfying the Ampere balance

```text
C^T M_mu^-1 b0 = M_sigma0 e0 + s_e(0^-)
b0 = C a
```

This route is internally consistent and is tested by the discrete residual.
However, it is not yet a quantitative acceptance proof against empymod for the
near-source `Hz` component.  A diagnostic `initial_magnetic_field:
biot_savart_wire` route instead uses `geoana.em.static.LineCurrentWholeSpace` to
sample the open-domain finite-wire vector potential at mesh edges, projects it
to edge integrals, and applies the discrete curl.  This gives a divergence-free
face `B0` and matches the finite-wire Biot-Savart static scale near the receiver,
but by itself it does not include the full grounded-return-current MMR
correction.  SimPEG's grounded-wire EB implementation also uses its DC electric
initial field, but its magnetic initial field machinery is not a drop-in EB
reference for the open grounded wire.  The production validation plan must
therefore treat magnetic initial-field construction as a first-class item.

With the non-CPML source-difference electric solve, `biot_savart_wire` no longer
pollutes `E(t)`, but it is still not a production `Hz(t)` solution: its
non-Ampere-balanced component is preserved by the Faraday update and appears as a
nearly static magnetic offset in positive-time receiver data.  A correct
near-source `Hz` acceptance run still needs an Ampere-balanced magnetic initial
field that also has the finite-wire/return-current near-source scale, or an
equivalent primary-secondary/MMR magnetic-field recovery.

The optional receiver setting `magnetic_receiver_mode: current_biot` is the first
MMR-style recovery path.  It samples magnetic receivers from

```text
H(r,t) = (1/4 pi) integral J_c(r',t) x (r-r') / |r-r'|^3 dV'
         + H_wire(r,t)
```

where `J_c = sigma_inf E - sum_i delta_sigma_i y_i` is reconstructed at cell
centers from the edge electric field and Debye memories.  The reconstruction is
mass-consistent with the finite-volume constitutive current:

```text
q_J = M_sigma_inf e - sum_i M_delta_sigma_i y_i
u_J = M_1^-1 q_J
J_c = A_ec u_J
```

where `M_1` is the unit edge inner-product matrix and `A_ec` is
`average_edge_to_cell_vector`.  This avoids replacing the edge-integrated
current in the time-step equations with the weaker pointwise approximation
`sigma_inf A_ec e - sum_i delta_sigma_i A_ec y_i`.  The volume integral uses
midpoint quadrature; `magnetic_recovery_subdivisions` splits each cell into
`n^3` midpoint samples for near-receiver accuracy.  This mode changes only
receiver data; the stored finite-volume `b` field is still the state advanced by
Faraday.  On the current 50 m wire / 10 m offset diagnostics, `current_biot`
removes the static non-balanced `Hz` offset from a diagnostic
`biot_savart_wire` initial field.  It is still a receiver-side MMR approximation,
not final magnetic acceptance.

The diagnostic `magnetic_receiver_mode: edge_current_biot` uses the same dual
edge current vector without cell averaging.  For each edge `k` with location
`r_k`, direction unit vector `a_k`, and current moment

```text
q_k = [M_sigma_inf e - sum_i M_delta_sigma_i y_i]_k
```

the receiver field is approximated by

```text
H_edge(r,t) = (1/4 pi) sum_k q_k a_k x (r-r_k) / |r-r_k|^3 + H_wire(r,t).
```

This preserves the finite-volume current moment before any cell-center
projection, but it is still only a point quadrature of edge basis functions. It
exists to rule in/out local current-recovery hypotheses and must not be treated
as an accepted MMR formula without empymod convergence evidence.

The diagnostic `magnetic_receiver_mode: edge_basis_biot` instead converts the
dual edge-current moments to a unit-edge-mass current field and reconstructs the
current inside each TensorMesh cell with lowest-order edge basis functions:

```text
u_J = M_1^-1 q_J
J_x(xi,eta,zeta) = bilinear_yz(u_x on the four x-edges of the cell)
J_y(xi,eta,zeta) = bilinear_xz(u_y on the four y-edges of the cell)
J_z(xi,eta,zeta) = bilinear_xy(u_z on the four z-edges of the cell)
```

The reconstructed current is integrated with midpoint subcell Biot-Savart
quadrature.  This is a better finite-volume diagnostic than treating edge
moments as point currents, but it is still only a receiver recovery hypothesis;
it must be judged by empymod validation.

The diagnostic `magnetic_receiver_mode: edge_basis_cell_biot` keeps the same
edge-basis reconstruction but applies the Debye constitutive law locally inside
each cell:

```text
E_q = N_e(xi,eta,zeta) e
y_{i,q} = N_e(xi,eta,zeta) y_i
J_q = sigma_inf,cell E_q
      - sum_i lambda_i delta_sigma_i,cell y_{i,q}
```

where `lambda_i` may be a scalar, a component vector, or the diagnostic
`sigma_inf / sigma_0` ratio.  This differs from `edge_basis_biot`, which first
forms a global dual edge current and divides by `M_1`; that route can smear
material/IP contrasts onto edges shared by multiple cells before the local
receiver integral.

For Debye-IP diagnostics, `magnetic_recovery_polarization_scale` can replace the
receiver-side current by

```text
J_c(lambda) = sigma_inf E - lambda sum_i delta_sigma_i y_i.
```

The default `lambda=1` is the strict constitutive current used by the solver.
Non-unit values are not a production physical model; they are a controlled way
to test whether the remaining `Hz` error is localized in the magnetic receiver
mapping of the polarization memory current.  The compare CLI can apply this
only when recomputing `current_biot` data from a saved field file.

The related primary-secondary diagnostic adds the initial equilibrated Debye
memory as a second basis:

```text
J_c(lambda, gamma)
  = sigma_inf E - lambda sum_i delta_sigma_i y_i(t)
    + gamma sum_i delta_sigma_i y_i(0^-).
```

The default `gamma=0` recovers the strict current when `lambda=1`.  Nonzero
`gamma` is diagnostic only; it exists to test whether the empymod switch-off
magnetic response is exposing a missing receiver-side primary-secondary memory
term.  In saved-field comparisons, prescribe it with
`--magnetic-recovery-initial-polarization-scale`; this direct knob is kept
separate from the fitted memory-scale options.

Use `atem3d.initial_field_diagnostics_cli` to make this tradeoff reproducible.
For the aligned 50 m wire / 10 m offset diagnostic, `ampere` gives
`Hz0 = 0.00711 A/m` and relative Ampere residual `2.5e-13`, while
`biot_savart_wire` gives `Hz0 = 0.01635 A/m` and relative Ampere residual
`7.67`.  Adding the simple `discretize.boundary_edge_vector_integral` term from
the open-domain Geoana vector potential to the finite-domain vector-potential
solve was also tested; its RHS norm is only about `1.8e-3` versus total current
norm about `17.7` on this mesh, and it leaves `Hz0` essentially unchanged.  This
rules out a simple boundary-integral correction for the current FV/EB prototype.

## Boundary Treatment

The `boundary.kind: cpml` option adds split-curl convolutional PML memories to
the direct time-domain EB equations.  Write the directional split of the edge
curl as

```text
C = C_x + C_y + C_z
```

For Faraday, each directional derivative has a face memory:

```text
psi_f,d^{n+1} = b_f,d psi_f,d^n + c_f,d C_d e^{n+1}
S_f e^{n+1}
  = sum_d [(1/kappa_f,d) C_d e^{n+1} + psi_f,d^{n+1}]
```

Thus

```text
b^{n+1} = b^n - dt_n (C_f,eff e^{n+1} + r_f^n)
C_f,eff = sum_d diag(1/kappa_f,d + c_f,d) C_d
r_f^n = sum_d b_f,d psi_f,d^n
```

For Ampere, each directional adjoint-curl derivative has an edge memory:

```text
psi_e,d^{n+1} = b_e,d psi_e,d^n + c_e,d C_d^T M_mu^-1 b^{n+1}
S_e M_mu^-1 b^{n+1}
  = A_e,eff b^{n+1} + r_e^n
A_e,eff = sum_d diag(1/kappa_e,d + c_e,d) C_d^T M_mu^-1
r_e^n = sum_d b_e,d psi_e,d^n
```

Substituting the Faraday update into Ampere gives the implicit CPML edge solve:

```text
[A_e,eff C_f,eff + (1/dt_n) M_sigma_eff] e^{n+1}
  = (1/dt_n) A_e,eff b^n
    - A_e,eff r_f^n
    + (1/dt_n) r_e^n
    + (1/dt_n) sum_i alpha_i M_delta_sigma_i y_i^n
    - (1/dt_n) s_e^{n+1}
```

The CPML coefficients use the recursive-convolution form

```text
b_d = exp[-(sigma_d/kappa_d + alpha_d) dt_n]
c_d = sigma_d (b_d - 1) / (sigma_d kappa_d + kappa_d^2 alpha_d)
```

with polynomial tapers in the outer `thickness_cells`.  When
`thickness_cells = 0` or `sigma_max = 0`, `b_d = 1`, `c_d = 0`, `kappa_d = 1`,
all CPML memories stay zero, and the system reduces to the original EB finite
volume equations.

The older `boundary.kind: sponge` option adds a smooth conductivity increase in
an outer shell:

```text
sigma_shell = sigma_physical + sigma_extra(distance_to_boundary)
```

The sponge config also carries two grounded-source safeguards.  First,
`apply_to_initial: false` keeps the DC/on-time initial field on the physical
model and applies the sponge only to the transient time-step operator.  This is
important for step-off grounded wires because the long-on electric field and
MMR magnetic field are physical source balances, not absorbing-boundary
quantities.  Second, `sides` can limit the shell to named boundaries
(`x_min`, `x_max`, `y_min`, `y_max`, `z_min`, `z_max`).  For the current
`z_up` surface-source H/J examples the intended sponge is side and bottom only,
for example `sides: [x_min, x_max, y_min, y_max, z_min]`, so the physical
ground surface is not replaced by a conductive top sponge.

This sponge is an absorbing shell, not strict CPML/CFS-PML.  Either boundary
must be accepted only after padding/thickness/parameter sweeps show receiver
curves in the physical region are insensitive to the boundary.

Active CPML matrices are generally nonsymmetric because the effective stretched
Faraday and Ampere curls are not adjoints under the same inner product.  The
implementation therefore allows `linear_solver: pardiso` for CPML by using
PARDISO's nonsymmetric mode, while CG remains disabled for active CPML.  This is
verified against the general sparse direct solver on small active-CPML tests and
on the smaller 50 m/IP smoke example.  The refined 52k-edge no-IP target mesh
still times out during CPML factorization in the current Windows/Conda setup, so
production CPML acceptance still needs either a smaller sweep design or a better
large nonsymmetric solver strategy.

examples/debye_ip_line_exeyhz_xy6pad_cpml_stored_b.yaml
examples/debye_ip_line_exeyhz_xy6pad_cpml_biot_stored_b.yaml

The source-strength diagnostic isolates one part of the electric mismatch.

`strength != 0` returns the response for the given finite source/receiver
length and source strength.  Therefore the physical validation baseline remains
`strength=1 A` for this config, not the fitted diagnostic scale.

## H/J Formulation Status

The local SimPEG installation (`0.25.1`) includes
`Simulation3DMagneticField` and `Simulation3DCurrentDensity`, which use an HJ
formulation: magnetic field on edges and current density on faces.  These
classes are useful references for non-IP TDEM operators, but they are not a
drop-in solution for this project because the Debye-IP constitutive law is in
conductivity form and requires extra time-domain memory variables.  In an H/J
formulation, Ampere gives

```text
j = C_h h - s_e
```

where `C_h` is the edge-to-face curl in the HJ placement.  With one or more
Debye conductivity terms,

```text
j = sigma_inf e - sum_i delta_sigma_i y_i
tau_i d y_i / dt + y_i = e
```

the electric field cannot be obtained by applying a static resistivity matrix to
`j`.  Instead,

```text
e = rho_inf (j + sum_i delta_sigma_i y_i)
rho_inf = 1 / sigma_inf
```

and each memory obeys the coupled equation

```text
tau_i d y_i / dt + y_i
  = rho_inf (j + sum_k delta_sigma_k y_k).
```

For a single Debye term, backward Euler gives a local eliminated relation

```text
y^{n+1}
  = [tau y^n + dt rho_inf j^{n+1}]
    / [tau + dt (1 - rho_inf delta_sigma)]

e^{n+1}
  = rho_inf (j^{n+1} + delta_sigma y^{n+1}).
```

For multiple Debye terms, the `y_i^{n+1}` are coupled through
`sum_k delta_sigma_k y_k^{n+1}` at each material cell/face, so the HJ update
needs either a small local memory-block elimination or an augmented global
system.  The implemented local elimination writes the inverse law as

```text
e^{n+1} = rho_eff j^{n+1} + e_hist

D_i = tau_i + dt
A = sum_i delta_sigma_i / D_i
P = sum_i delta_sigma_i tau_i y_i^n / D_i
rho_eff = rho_inf / (1 - dt rho_inf A)
e_hist = rho_inf P / (1 - dt rho_inf A)
```

After solving for `j^{n+1}` or `h^{n+1}`, the memories are updated with the
same backward-Euler relation `y_i^{n+1} = alpha_i y_i^n + beta_i e^{n+1}`.
Faraday then advances magnetic field by

```text
M_mu (h^{n+1} - h^n) / dt + C_h^T M_e e^{n+1} = source terms.
```

The local inverse constitutive pieces are implemented as
`DebyeIPModel.inverse_constitutive_coefficients(memories, dt)` and
`DebyeIPModel.inverse_constitutive_update(j, memories, dt)`.  They are
unit-tested against the no-IP Ohmic limit, the single-Debye closed form, the
multi-Debye coupled equations, and the coefficient identity
`e = rho_eff j + e_hist`.

The H/J helpers in `atem3d.hj` now expose
`hj_magnetic_system_matrix`, `hj_magnetic_rhs`, `hj_magnetic_step`, and the
multi-step `HJMagneticSimulation` container.  YAML configs can select this route
with `formulation: hj`; the container supports the same `direct`, `cg`, and
`pardiso` solver names as the EB runner, with repeated-time-step matrix/factor
caching.  The system matrix is

```text
A_h = C^T M_f(rho_eff) C + M_e(mu) / dt
```

and the no-IP matrix and multi-step fields are tested directly against SimPEG
`Simulation3DMagneticField`.  The RHS includes the Debye history term

```text
rhs_h = M_e(mu) h^n / dt
        + C^T M_f(rho_eff) s_e^{n+1}
        - C^T M_f(1) e_hist
        + s_m^{n+1}.
```

The one-step prototype is tested by solving for `h^{n+1}`, recovering
`j^{n+1}=C h^{n+1}-s_e^{n+1}`, applying the inverse Debye update, and verifying
the eliminated Faraday equation.  The grounded-wire H/J electric source uses
SimPEG's face projection

```text
s_e = line_through_faces(mesh, wire_nodes, normalize_by_area=True)
```

through `GroundedWireSource.face_vector(...)`, with the same step-off
left-limit convention as the EB edge source.  This face source is tested against
SimPEG `LineCurrent.Mfjs`, and the H/J one-step test verifies the sourced Ampere
current `j = C h - s_e`.

For layered or otherwise cell-centered Debye parameters, the H/J prototype does
not first average `sigma_inf` and `delta_sigma_i` to faces and then invert.
That order is inconsistent with the no-IP H-form operator near discontinuous
interfaces.  The implemented cell-centered path now forms the eliminated
coefficients in cells,

```text
sigma_eff,c = sigma_inf,c - sum_i beta_i delta_sigma_i,c
rho_eff,c = 1 / sigma_eff,c
q_i,c = rho_eff,c alpha_i delta_sigma_i,c
```

and then assembles the same face inner products used by SimPEG's H/J operator:

```text
M_f(rho_eff,c)
e_hist,f = sum_i [diag(M_f(q_i,c)) / diag(M_f(1))] y_i,f^n
```

Face-centered or scalar Debye parameters can still use the purely local inverse
coefficients.  The older `face_project_debye_model(mesh, ip_model)` helper is
kept for diagnostics and tests of the raw face-mass projection, but the layered
H/J solver path now uses the cellwise effective-resistivity assembly.  Unit
tests verify that layered Debye matrices assemble with `M_f(rho_eff,c)`, that
the RHS uses the projected `rho_eff alpha delta` history field, and that a
layered Debye H/J one-step solution satisfies both Faraday and the cellwise
inverse constitutive recovery.

`HJMagneticSimulation` stores time-node `h`, face `e`, and Debye memory histories
and advances each step using the face source at `t^{n+1}`.  Tests cover a
multi-step no-IP decay and a multi-step layered Debye grounded-wire source,
checking Faraday and the cellwise effective-resistivity inverse law at every
positive time.
Point receivers can now sample H/J states directly: electric components
`Ex/Ey/Ez` are interpolated from face fields `Fx/Fy/Fz`, magnetic components
`Hx/Hy/Hz` are interpolated from edge fields `Ex/Ey/Ez`, and `B` or `dB/dt`
components multiply the edge `H` values by `mu`.  `HJMagneticSimulation` stores
these receiver samples in `result.data`.  For near-source magnetic receivers,
H/J also supports `magnetic_receiver_mode: current_biot`: the recovered face
current `C h - s_e` is averaged to cell-centered vector current density and
integrated with the same receiver-side Biot operator used by EB diagnostics.
It also supports `magnetic_receiver_mode: face_basis_cell_biot`, which
reconstructs H/J face-`E` and Debye memories locally inside each cell before
applying that cell's own `sigma_inf` and `delta_sigma_i` in the Biot integral.
These modes change only the receiver recovery for `H/B` components; the H/J
time-step system remains unchanged.

The source-history diagnostic hook is now also wired into the H/J receiver
paths.  When `magnetic_recovery_source_history` is supplied with an H/J Biot
receiver mode, `receiver_matrix: auto` maps `current_biot` to an explicit
face-current Biot matrix and `face_basis_cell_biot` to an explicit face-basis
Biot matrix.  The source moments are built from the signed H/J face source
`-source.initial_face_vector(mesh)`, consistent with the Ampere current
`j = C h - s_e`.  The `prescribed_source_moments` kind remains a
disabled-by-default evaluation hook for coefficients supplied by a derivation
or a documented diagnostic experiment; it is not a hard-coded empirical
correction.  The new diagnostic kind `initial_polarization_source_moments`
computes its coefficients directly from the initial Debye polarization current
`-delta_sigma*y0`, the source-moment basis, and the selected receiver matrix.

complete production law: `outputs/initial_polarization_source_history_candidate_source_centered_eval.json`

The H/J route now initializes the long-on-time electric/DC part for
galvanic sources.  With

```text
D = diag(cell_volumes) face_divergence
G = D^T
A_dc = D M_f(rho_0)^-1 G
rho_0 = 1 / sigma_0
```

the face source `s_e(0^-)` enters as `D s_e(0^-)`, and the implementation solves
the full cell-centered potential system:

```text
A_dc phi = D s_e(0^-)
j_0 = -M_f(rho_0)^-1 G phi
M_f(1) e_0 = M_f(rho_0) j_0
```

For Debye IP, the initial memories are set to this `e_0`, representing
long-on-time equilibrium.  Tests verify the cell-centered balance on the
complete DC equations, the low-frequency resistivity relation, and automatic
memory initialization in `HJMagneticSimulation`.  This full solve is important:
pinning or dropping a cell equation corrupts the final-cell current balance and
breaks parity with SimPEG's H/J `jInitial` and `hInitial`.

The H/J prototype also builds a grounded-source MMR magnetic initial field.
Following SimPEG's H/J line-source route, a face vector potential `a` is solved
from

```text
A_mmr a = s_e(0^-) + j_0
A_mmr = C M_e(mu)^-1 C^T
        - D^T diag(mu^-1 / cell_volume) D
h_0 = M_e(mu)^-1 C^T a
```

where the second term is the divergence stabilization used by the MMR solve.
`HJMagneticSimulation` uses this `h_0` by default when sources have initial
fields and no explicit `initial_h` is provided.  Tests verify that the MMR field
is finite, non-zero for a grounded wire, reduces the sourced Ampere residual,
and is actually used by the simulation initializer.

the recovered current into Ohmic, polarization-x, polarization-y, and
polarization-z contributions and fitting all three `Hz` receivers together

`lambda_x = 1.0153363818712349`, `lambda_y = 1.0184707804483801`, and an
irrelevant `lambda_z` for `Hz`.  The CLI now accepts this diagnostic form as
`--magnetic-recovery-polarization-scale sx,sy,sz`.  The full-line report
`outputs/current_debye_line_exeyhz_component_scale_sub1_t010_1ms_report.json`
uses `1.0153363818712349,1.0184707804483801,1.0` and gives, over 0.1-1 ms,
`Ex` relative L2 `0.038-0.081`, `Ey@x=+-20` relative L2 `0.055`, and `Hz`
relative L2 `0.015-0.026` at all three receiver positions.  `Ey@x=0` remains a
symmetry-near-zero component and should be judged by absolute error.  This is
not yet a production formula because the component weights were fit from
empymod, but it is the strongest evidence so far that the remaining task is a
component/geometry-dependent magnetic recovery derivation rather than the
direct time-domain Debye solve itself.

These pieces also explain why simply switching the existing conductivity-form EB

needs the inverse constitutive relation with coupled IP memories, not the EB
`sigma_eff` matrix.

## Coordinate Convention For empymod

ATEM3D examples intended for SimPEG-style meshes use `coordinate_system: z_up`.
empymod uses positive depth downward.  The compare helper maps

```text
z_empymod = -z_atem3d
electric vertical receivers in z_up use dip = -90 degrees
magnetic axial vertical receivers in z_up use dip = +90 degrees
horizontal magnetic axial components in z_up receive an output factor of -1
```

The report metadata stores the coordinate system used for the comparison.  Layer
boundaries in z-up configs, for example `top: 0`, `bottom: -40`, map to empymod
depth interval `0..40`.

## empymod Acceptance Sequence

Use this sequence before claiming algorithmic correctness:

1. No IP, no sponge, layered mesh with interfaces exactly on z nodes.
2. Confirm source projection, current strength, receiver component, sign, and
   positive-time step-off convention.
3. Compare `Ex`, `Ey`, `Hz`, and optionally `dBzdt` with empymod using finite
   source integration (`srcpts >= 3`; use about `51` or a convergence sweep for
   the 50 m wire / 10 m offset near-source geometry).
4. Run mesh refinement around the 50 m wire and the 10 m offset receivers.
5. Run physical-padding and boundary sweeps.  Accept a sponge or CPML only when
   receiver curves in the physical region stop changing.
6. Add one Debye term with known parameters and repeat the comparison.
7. Add multi-Debye/Pelton fitting and compare to empymod through `func_eta`.

The current smoke examples exercise this pipeline, but the no-IP empymod errors
are still too large for acceptance.  They should be read as diagnostics, not as a
successful analytic validation.

For boundary-only convergence, `atem3d-boundary-benchmark` can compare several
ATEM3D cases against the most conservative case without calling empymod.  The
compact spec format in
`examples/boundary_benchmark_base_config_smoke.yaml` uses a shared
`base_config`, per-case `overrides`, and `data_only: true`; this is the intended
template for padding/CPML parameter sweeps once the candidate meshes are chosen.
The same benchmark accepts an optional `absolute_tolerance`.  A component passes
if its relative `L_inf` error is within `tolerance` or its absolute `L_inf`
error is within `absolute_tolerance`, and reports `passed_by` for each
component.  This avoids rejecting boundary convergence solely because a
symmetry-zero component such as centerline `Ey` has a tiny reference amplitude.

The in-memory empymod validation path uses the same pass/fail convention.  Pass
`--time-min`, `--time-max`, `--tolerance REL`, and optionally
`--absolute-tolerance ABS` to `atem3d-validate-empymod` (or the module form
`python -m atem3d.empymod_validation_cli`).  Each component passes if its
relative `L_inf` error is within `REL`, or its absolute `L_inf` error is within
`ABS`; the JSON report records top-level `passed`, `relative_linf_max`,
`absolute_linf_max`, and per-component `passed_by`.  If no gate is supplied,
`passed` is reported as `null` and component `passed_by` is
`not_evaluated`.  The time window is applied after the positive-time and
`--skip-positive-times` selection, and is recorded under
`metadata.empymod.time_window`.  Sweep reports aggregate `passed` over all
cases, and the CLI option `--require-pass` returns exit code `1` unless that
aggregate is exactly `true`.

For fast CLI smoke checks, use `compare_cli --receiver-indices ...` to compare a
small subset of receiver columns before launching a full receiver-line run.  On
the Windows/Conda environment used here, set `NUMBA_CACHE_DIR` to the project
`.numba_cache` directory before invoking empymod; otherwise Numba startup and
cache discovery can dominate short comparisons.

One important diagnostic is empymod source normalization.  empymod's finite
`bipole` response with `srcpts >= 3` integrates the finite source geometry,
while `strength` is the physical current multiplier.  Near-source finite-wire
diagnostics are sensitive to this quadrature: for the 50 m wire at 10 m offset,
`srcpts=5` gives a poor low-frequency finite-source reference, while
`srcpts=51` is much closer to the converged source integral.  The compare CLI
therefore defaults to `51`.  It also provides `--empymod-strength` as a
diagnostic override, but the validation baseline should use the ATEM3D source
current from the config.  Refined time-step diagnostics show that multiplying
the 50 m wire by `strength=50` double-counts the source length and can hide
time-discretization error.

For large-domain diagnostics use the optional PARDISO solver when available:

```yaml
solver:
  type: pardiso
```

The fallback iterative option is CG:

```yaml
solver:
  type: cg
  tolerance: 1.0e-7
  maxiter: 10000
  preconditioner: jacobi
```

Repeated time-step blocks can be specified as `[dt, repeat]` so early-time
convergence can be tested without long hand-written YAML lists.

On a larger-domain no-IP diagnostic with layer boundaries aligned at `z = 0`
and `z = -40`, switching the refined case from Jacobi-CG to PARDISO allowed a
previously non-convergent run to complete.  With ten `0.1 ms` steps to `1 ms`
and physical `strength=1 A`, the default `ampere` initial field gives relative
L2 errors of about `0.184` for `Ex@x=0` and `0.843` for `Hz@x=0`.  The diagnostic
`biot_savart_wire` initial field gives about `0.217` for `Ex@x=0` and `0.275`
for `Hz@x=0`.  These numbers are still diagnostics, not acceptance results:
magnetic initial-field construction, grounded return-current treatment,
magnetic receiver definitions, time-step refinement, mesh refinement, and
mesh/boundary convergence remain separate validation items.

With one hundred `0.01 ms` steps, source-difference E-form time stepping,
`biot_savart_wire` initial flux, `magnetic_receiver_mode: current_biot`, and
`magnetic_recovery_subdivisions: 5`, the 0.1-1 ms comparison gives about `0.245`
relative L2 for `Ex@x=0` and `0.105` for `Hz@x=0`.  The last ten gates improve
for `Ex` to about `0.014`, but `Hz` remains about `0.619`, so this recovery
reduces the static offset and near-receiver quadrature error without closing the
late-time magnetic validation.

Increasing only the x/y physical padding from four expanding cells per side
(`x` roughly `[-565, 565] m`) to six expanding cells per side (`x` roughly
`[-1003, 1003] m`) while keeping the 5 m core, `0.01 ms` time step, and

`0.248` for `Ex@x=0` and `0.0546` for `Hz@x=0`.  The last ten gates become about
`0.040` for `Ex` and `0.041` for `Hz`.  This identifies finite-domain truncation
as a dominant cause of the previous late-time magnetic error; production runs
need padding/CPML convergence, not just local receiver quadrature.

The same six-padding no-IP setup was also run on a three-point receiver line
parallel to the wire (`x = -20, 0, 20 m`, `y = 10 m`) with `Ex`, `Ey`, and `Hz`.
Over 0.1-1 ms, `Hz` is about `0.051-0.055` relative L2 at all three points and
the last ten gates are about `0.041`.  `Ex` is about `0.243-0.248` over the full
0.1-1 ms window but about `0.040` over the last ten gates.  `Ey` is a weak

about `1.4e-15`.  At `x=+-20 m`, `Ey` relative L2 is about `0.48` over 0.1-1 ms,
but its absolute L-infinity error is only about `1.8e-7`, two to three orders
below the main `Ex` response.  Validation reports therefore include
`absolute_linf` in addition to relative norms.

A first one-Debye IP validation was run on the same six-padding geometry with
the low-frequency conductivities kept equal to the no-IP model:
`sigma_inf = 0.012, delta_sigma = 0.002, tau = 0.001 s` in the upper earth and
`sigma_inf = 0.036, delta_sigma = 0.006, tau = 0.001 s` in the lower earth.
Using empymod through `func_eta`, the 0.1-1 ms `Ex@x=0` relative L2 is about
`0.038`, with an optimal-scale shape residual about `0.0024`.  This is strong
evidence that the direct time-domain Debye coupling and empymod conductivity
hook are aligned for electric fields.  The same run gives `Hz@x=0` relative L2
about `0.50`, and the last ten gates about `0.77`; the remaining IP magnetic
error is therefore assigned to receiver-side current/MMR recovery and magnetic

Increasing x/y padding further to eight expanding cells per side (`x` roughly

(`Hz@x=0` is about `0.52` over 0.1-1 ms and about `0.82` over the last ten

finite-domain truncation alone.

The `current_biot` reconstruction was then tightened from pointwise

`outputs/magnetic_recovery_mode_diagnostics_xy6pad.json` records the receiver
recovery alternatives tested on the same saved fields.  `current_biot_sub5`
remains the best magnetic receiver path among these candidates: no-IP `Hz@x=0`

For this receiver-side work, `atem3d.compare_cli` supports
`--recompute-current-biot`, `--recompute-edge-current-biot`,
`--recompute-edge-basis-biot`, `--recompute-edge-basis-cell-biot`, and
`--magnetic-recovery-subdivisions N`; it also provides direct diagnostic scales
through `--magnetic-recovery-polarization-scale` and
`--magnetic-recovery-initial-polarization-scale`, plus the diagnostic fit flags
`--fit-magnetic-recovery-component-scale` and
`--fit-magnetic-recovery-memory-scale` plus the per-column variant
`--fit-magnetic-recovery-memory-scale-per-receiver`.  The command loads saved `e` and `b`
fields from an HDF5 result, reconstructs the Debye memories from the saved
electric history, recomputes receiver data using the selected magnetic recovery
path, and then compares that recomputed data to empymod.  This makes
magnetic-recovery changes reproducible without rerunning a large implicit solve.
For in-memory mesh/time/boundary sweeps, use the corresponding runtime config
keys such as `magnetic_receiver_mode`, `magnetic_recovery_subdivisions`,
`magnetic_recovery_polarization_scale`, and
`magnetic_recovery_source_primary_delta6` /
`magnetic_recovery_source_primary_delta6_basis`; the empymod validation report
records these under `metadata.atem3d`.

The ATEM3D `dBdt` receiver currently reports a backward-Euler step-average

```text
(B^{n+1} - B^n) / dt_n
```

using the previous stored magnetic state.  At the first post-step-off time this
includes the large transition from the on-current static magnetic field at
`t=0^-`.  empymod's `mrec='b'` applies an `i omega mu` factor in the frequency
domain and, with `signal=-1`, returns the positive-time switch-off `dB/dt`
response.  Do not use first-step `dBdt` errors as an acceptance metric until the
comparison explicitly chooses either step-average derivatives or positive-time
point derivatives on both sides.

The compare CLI provides `--skip-positive-times N` for this diagnostic purpose.
On the current coarse no-IP `dBdt` scaffold, skipping only the first positive
time reduces the center `dBzdt` error from roughly `705` relative L2 to roughly
`0.44`; this confirms that the first sample is dominated by receiver definition.
It is not yet an acceptance result, because the later-time `Ex` and magnetic
curves still show strong finite-domain/coarse-grid effects.
