# Lei 2023 无 IP + Song 2025 IP/no-IP SOTEM 三求解器验证设计

## 1. 目标与结论边界

本工作建立一个分两级、可复现、非循环的电性源瞬变电磁（SOTEM）验证套件：

1. **Lei 2023 无 IP 基础门**：先验证源、DC 初场、Maxwell 时域推进、边界和接收器；
2. **Song 2025 IP/no-IP 极化门**：在同一水平层状模型、同一离散设置下分别计算无极化总场、极化总场和纯极化增量。

参与比较的三条独立计算路径为：

1. `empymod` 有限长接地电偶极子层状介质半解析响应；
2. 本仓库基于 SimPEG/Discretize 算子的时域有限体积路径；
3. FEniCSx/DOLFINx 三维 Nédélec 边元时域路径。

主要目标是验证并调试 FEniCSx 的无 IP Maxwell 部分和 Debye 极化记忆部分。无 IP 门未通过时，不运行或解释极化验收。两级基准都通过后，只能声明“内部数值验证通过”，不能替代工程、现场或实测验证。

本轮不包含 Song 2025 的三维极化体。三维极化体只有在水平极化层通过后才能另立规格。

## 2. 文献依据

### 2.1 无 IP 基础门：Lei 2023

- Lei et al., *Shadow effect and source overprint effect of short-offset transient electromagnetic method*, Journal of Geophysics and Engineering, 20(2), 439-454.
- DOI: [10.1093/jge/gxad020](https://doi.org/10.1093/jge/gxad020)
- 全文：[Oxford Academic](https://academic.oup.com/jge/article/20/2/439/7083017)

论文验证模型为 `100 Ω·m` 均匀半空间、`1000 m` 接地线源、`1 A` 电流、接收点 `(0, 800, 0) m`，比较 `Ex` 和 `dBz/dt`。论文采用电场旋度-旋度方程、切向电场 Dirichlet 外边界、后向欧拉时间离散和 Whitney/Nédélec 边元，并报告各时间道相对误差小于 `4%`。

### 2.2 IP/no-IP 极化门：Song 2025

- Song et al., *Analysis of 3D induced polarization effects of SOTEM*, Journal of Applied Geophysics, 233, 105613.
- DOI: [10.1016/j.jappgeo.2024.105613](https://doi.org/10.1016/j.jappgeo.2024.105613)
- 论文页面：[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S092698512400329X)

论文在同一网格上计算并比较有、无极化效应的 SOTEM 响应。水平极化层模型采用 `1000 m` 接地线源、`10 A` 电流、空气电导率 `1e-6 S/m`、半空间电导率 `0.01 S/m`、`300 m` 极化层，以及 Cole-Cole 参数 `M=0.3`、`tau=1 s`、`c=0.3`；论文以 `Ex` 和标记为 `Hz` 的磁响应展示 IP/no-IP 曲线。

两篇论文都没有提供可直接读取的完整逐时间道数据表。论文曲线数字化只能作为外部复现证据，必须保存原图、图轴标定、曲线标签和数字化误差；定量通过门以独立 `empymod` 层状解和两套收敛数值解为准。

## 3. 坐标、符号与公共约定

所有配置、CSV 和报告统一使用 `z_down`：

- `x`：线源正向；
- `y`：水平横向；
- `z = 0`：地表；
- `z > 0`：地下；
- `z < 0`：空气。

内部映射：

| 求解器 | 内部坐标 | 映射 |
|---|---|---|
| empymod | `z` 向下 | 原样使用 `z_down` |
| SimPEG/Discretize | `z` 向上 | `z_up = -z_down` |
| FEniCSx 当前管线 | `z` 向上 | `z_up = -z_down` |

转换只能发生在各适配器入口。输出必须转换回 `z_down`，并记录源端点顺序、电流方向、分量正方向、单位和磁场定义。

源与接收点在论文中位于 `z=0`。当前三维离散器要求其位于地下单元内部，因此规范数值深度取 `z_down=+0.1 m`。每个模型都要保存正式的 `z=0` 对 `z=0.1 m` empymod 灵敏度结果；该下移不能作为幅值校正参数。

## 4. Lei 2023 无 IP 规范模型

### 4.1 几何、材料和波形

| 项目 | 规范值 |
|---|---|
| A 电极 | `(-500, 0, +0.1) m` |
| B 电极 | `(+500, 0, +0.1) m` |
| 电流方向 | A 到 B，即 `+x` |
| 通电电流 | `1 A` |
| 接收点 | `(0, 800, +0.1) m` |
| 地下电阻率 | `100 Ω·m` |
| 数值空气电阻率 | `1e8 Ω·m` |
| 磁导率 | `mu0` |
| 极化 | 无 IP |
| 关断 | `t=0` 理想阶跃关断 |

关断前状态为 `1 A` 长时间通电后的 DC 稳态；`t=0` 后外加源为零。规范基准不得用有限斜坡关断替代理想阶跃后再与阶跃参考直接比较。

### 4.2 输出

- `1e-5 s` 到 `1e-1 s` 的 `41` 个等对数时间道；
- 严格验收：`Ex_V_per_m`、`dBzdt_T_per_s`；
- 诊断：`Hz_A_per_m`、`Bz_T`、`Ey_V_per_m`。

## 5. Song 2025 IP/no-IP 规范模型

### 5.1 规范化几何

论文层状介质具有水平平移不变性。把现有论文工作几何平移到源中心，并保留 `500 m` 横向偏移：

| 项目 | 规范值 |
|---|---|
| A 电极 | `(-500, 0, +0.1) m` |
| B 电极 | `(+500, 0, +0.1) m` |
| 电流方向 | A 到 B，即 `+x` |
| 通电电流 | `10 A` |
| 接收点 | `(0, -500, +0.1) m` |
| 关断 | `t=0` 理想阶跃关断 |

IP 和 no-IP 必须使用完全相同的源、接收点、网格、边界、DC 电阻率、时间步、线性求解器容差和接收器算子。唯一物理差别是极化参数。

### 5.2 材料

| 区域 | 深度范围 `z_down` | no-IP | IP |
|---|---:|---|---|
| 空气 | `z<0` | `sigma=1e-6 S/m` | 相同 |
| 上部层 | `0<=z<=300 m` | `rho=100 Ω·m`, `M=0` | `rho0=100 Ω·m`, `M=0.3`, `tau=1 s`, `c=0.3` |
| 下伏半空间 | `z>300 m` | `rho=100 Ω·m`, `M=0` | 相同无 IP 背景 |

Cole-Cole 采用电导率形式：

`sigma*(i omega) = sigma_inf [1 - M / (1 + (i omega tau)^c)]`

并强制

`sigma0 = sigma_inf (1-M)`。

因此极化层 `sigma0=0.01 S/m`、`sigma_inf=0.0142857142857 S/m`。no-IP 配对模型保持相同 DC 电导率 `0.01 S/m`，只令 `M=0`。

### 5.3 Cole-Cole 到 Debye/Prony

FEniCSx 和 SimPEG/Discretize 时域路径使用相同目标 Cole-Cole 材料，但分别装配自己的离散系统。材料在场求解前拟合为 `16` 个 Debye 极点：

- 拟合频率：`1e-3 Hz` 到 `1e4 Hz`；
- 频域复电导率相对 L2 误差必须 `<=1%`；
- 必须精确强制 DC 电导率约束；
- 禁止根据时域响应重新调整极点或幅值。

现有实现的只读预检得到 16 极点相对 L2 误差约 `0.573%`；正式运行仍须在 manifest 中重新计算并记录。

### 5.4 输出和磁场单位

时间道为 `1e-5 s` 到 `1 s`，每十倍频程 `10` 个间隔，共 `51` 个等对数时间道。

规范输出：

- `Ex_V_per_m`：论文和三代码严格验收；
- `Hz_A_per_m`：三代码严格验收；
- `Bz_T = mu0 * Hz`：与论文 nT 图轴对照；
- `dBzdt_T_per_s`：三代码严格验收，不从数字化论文曲线求导；
- `Ey_V_per_m`：对称性诊断，其峰值必须不超过 `Ex` 峰值的 `0.1%`。

论文把磁响应标记为 `Hz`，但图轴使用 nT。报告必须同时保存 `Hz_A_per_m` 和 `Bz_T`，不得静默混用名称和单位。

每个求解器必须输出：

1. no-IP 总场；
2. IP 总场；
3. 纯极化增量 `delta_IP = IP - noIP`。

## 6. 三条独立计算路径

### 6.1 empymod 层状半解析参考

- 两个模型均使用有限长 bipole，`srcpts>=3`；
- Lei 模型计算无 IP 阶跃关断响应；
- Song 模型分别计算频率无关 no-IP 和精确 Cole-Cole IP 响应；
- 直接输出电场、磁场和磁通密度时间导数，不通过数字化曲线求导。

### 6.2 SimPEG/Discretize 数值路径

无 IP 使用本仓库的 SimPEG/Discretize 有限体积路径。IP 使用本仓库在相同网格算子上实现的 Debye 记忆更新。上游 SimPEG 0.24 的 TDEM 类没有原生 Cole-Cole `M/tau/c` 映射，因此报告必须明确标注为“自编 SimPEG/Discretize-Debye 路径”，不能误写成上游 SimPEG 原生 IP 功能。

该路径必须独立完成源离散、DC 初场、时间推进、Debye 状态和接收器投影，不得读取 empymod 响应作为主场、校正量或初始场。

### 6.3 FEniCSx Nédélec 边元路径

使用电场旋度-旋度准静态方程、Nédélec 边元和后向欧拉。关断前 DC 初场、线源投影、材料矩阵、Debye 记忆、边界、时间推进和接收器投影均由 FEniCSx 独立完成。

`dBz/dt` 优先由 Faraday 定律的空间旋度获得，并与磁场时间变化诊断交叉检查。允许后续使用主场-二次场分解，但验收必须比较重建总场；均匀背景“二次场等于零”只能证明数据管道连通。

## 7. 不变量和材料门

任何场求解前必须通过：

1. 坐标转换、端点顺序、电流方向、源强、单位和阶跃波形；
2. `sigma0 = sigma_inf(1-M)`；
3. `M=0` 在装配层面退化为完全相同的 no-IP 系统；
4. 长时间通电的 Debye 初态满足 `chi_k(0)=E0`；
5. Prony 频域复电导率拟合误差 `<=1%`；
6. `Hz -> Bz -> dBz/dt` 的 `mu0` 因子和符号；
7. 求解器独立性守卫：SimPEG/FEniCSx 计算路径不得加载 empymod 响应。

任何一项失败都禁止进入高成本三维运行。

## 8. 误差指标和验收门槛

### 8.1 总场稳健误差

对带符号分量 `u` 定义

`U_peak = max_t |u_ref(t)|`

和

`e_robust(t) = |u(t)-u_ref(t)| / max(|u_ref(t)|, 0.01 U_peak)`。

分母下限防止零点附近的相对误差奇异，但不会删除任何时间道。另对 `|u_ref|>=0.01 U_peak` 的强响应道报告传统相对误差；弱响应道报告相对峰值的绝对误差。

### 8.2 极化增量误差

对 `delta_IP` 使用其自身参考峰值 `D_peak`。强极化响应道定义为 `|delta_ref|>=0.01 D_peak`：

- 强响应道报告相对误差；
- 弱响应道报告 `|delta-delta_ref|/D_peak`；
- 不删除早期接近零的极化时间道。

### 8.3 零交叉

零交叉定义为相邻非零带符号样本异号，并用线性插值计算交叉时间。禁止把单个低振幅点当成零交叉，也禁止事后裁剪时间窗。对参考与预测：

- 完整时间窗内零交叉数量必须一致；
- 对应零交叉时间相对差必须 `<=5%`。

### 8.4 分级通过门

1. **Lei/SimPEG 独立门**：收敛后 SimPEG 相对 empymod 的 `Ex`、`dBz/dt` 最大稳健误差 `<=3%`。
2. **Lei/FEniCSx 无 IP 门**：FEniCSx 相对 empymod 和收敛 SimPEG 的 `Ex`、`dBz/dt` 最大稳健误差 `<=5%`。
3. **Song no-IP 门**：SimPEG 和 FEniCSx 相对 empymod 的 `Ex`、`Hz`、`dBz/dt` 最大稳健误差 `<=5%`。
4. **Song IP 总场门**：SimPEG 和 FEniCSx 相对精确 Cole-Cole empymod 的同三分量最大稳健误差 `<=5%`。
5. **Song 极化增量门**：强 `delta_IP` 响应道最大误差 `<=10%`，弱响应道的峰值归一化绝对误差也必须 `<=10%`。
6. **论文复现证据**：Song `Ex/Bz` 与数字化曲线的趋势、数量级和反号位置一致；没有作者数值表时，不把该项伪装成精确逐点验收。

禁止经验幅值缩放、符号翻转拟合、时间平移、时间轴拉伸、删除时间道或平滑原始响应。门槛固定在运行前。

## 9. 空间、时间和边界收敛

采用一次只改变一个因素的三层序列，最后在组合细化模型上复核，避免完整 `3 x 3 x 3` 笛卡尔积。

### 9.1 空间层级

| 层级 | 线源附近 | 接收点附近 |
|---|---:|---:|
| S0 | `40 m` | `20 m` |
| S1 | `20 m` | `10 m` |
| S2 | `10 m` | `5 m` |

Song 的 no-IP/IP 配对必须复用同一网格。SimPEG 和 FEniCSx 只共享物理几何，不共享网格或离散权重。每次运行记录最小/最大单元、单元数、自由度数和网格生成参数。

### 9.2 时间层级

在固定输出时间道之间使用后向欧拉子步：

| 层级 | 每个输出区间最少子步数 |
|---|---:|
| T0 | `1` |
| T1 | `2` |
| T2 | `4` |

初始 `0 -> 10 us` 区间按同一规则细分。若使用自适应步进，必须输出实际步长并证明误差不大于对应固定层级。

### 9.3 边界层级

Lei 保持约 `2 km x 2 km x 1.5 km` 局部精细区，Song 保持论文约 `4 km x 4 km x 1 km` 局部区；两者均用分级粗化或明确的非拟合吸收方案测试远边界：

| 层级 | 最大远边界尺度 |
|---|---:|
| B0 | `25 km` |
| B1 | `50 km` |
| B2 | `100 km` |

相邻空间、时间和边界细化在强响应道的变化都必须 `<=2%`。海绵层或阻抗边界参数必须单独记录，不能拟合参考曲线。

## 10. 执行与调试顺序

严格按以下门推进：

1. 生成 empymod 的 Lei no-IP、Song no-IP 和 Song 精确 Cole-Cole IP 参考；
2. SimPEG/Discretize 路径完成 Lei no-IP 收敛；
3. FEniCSx 完成 Lei no-IP，未通过则停止；
4. SimPEG/Discretize 在同一 Song 网格上完成 no-IP、IP、`delta_IP` 和三层收敛；
5. FEniCSx 先完成 Song no-IP；
6. Song no-IP 通过后才启用 FEniCSx Debye 状态；
7. 粗网格确认符号、反号位置和幅值后，才启动 S2/B2 高成本计算。

FEniCSx 无 IP 调试顺序：

1. 坐标、端点顺序、电流、单位、波形；
2. `t=0-` DC 初场；
3. Nédélec 线源投影和总注入电流；
4. 接收点定位、插值和分量提取；
5. `curl(E)`、`dBz/dt` 符号和 `mu0`；
6. 弱式中的 `sigma`、`mu^-1` 和后向欧拉矩阵；
7. 时间、边界、空气和局部网格；
8. 线性求解器容差和性能。

IP 追加调试顺序：

1. Cole-Cole 参数约定与 `sigma0/sigma_inf`；
2. Prony 拟合和 DC 约束；
3. `chi_k(0)=E0` 初始记忆；
4. 后向欧拉 `alpha/beta` 更新；
5. Debye 历史电流符号和质量矩阵；
6. `M->0` 连续退化；
7. IP/no-IP 同网格配对和 `delta_IP` 后处理。

每次发现根因，先加入一个复现该错误的失败测试，再修复；不得用试比例因子代替诊断。

## 11. 当前已知验证缺口

现有 `corrected_model_runner` 的均匀无 IP 路径会选择零二次场投影器，而参考路径使用同一个 empymod 主场。因此零误差本质是“empymod 主场 + 0”与自身比较，只能标记为 `plumbing_pass`，必须从物理验收汇总中排除。

现有短时间 smoke 结果和完整时间窗结果不一致；历史完整 FEniCSx 运行曾出现 `Ex` 误差远大于 `100%`、`dBz/dt` 误差约 `80%`。这些是本轮要定位的失败证据，不得通过阈值调整、删点、平滑或覆盖旧报告消除。

现有 IP 单元测试主要证明材料公式、元数据和小型算子可运行，尚未证明完整 Song 层状总场与独立 Cole-Cole 参考一致。

## 12. 失败处理与状态

任何门失败时：

- 保留原始配置、CSV、日志、网格信息、异常栈和失败报告；
- 停止依赖该门的高成本阶段；
- 报告通过项、失败项、已排除原因和下一最小实验；
- 不覆盖旧 run-id，不把部分时间窗通过写成完整通过。

顶层状态只允许：

- `plumbing_pass`：管道连通，不代表物理正确；
- `noip_internally_validated`：仅 Lei 和 Song no-IP 门通过；
- `ip_internally_validated`：所有无 IP、IP 总场和极化增量门通过；
- `failed_with_reproducible_evidence`：保留可复现失败证据。

## 14. 完成定义

只有同时满足以下条件，才能声明 `ip_internally_validated`：

- 三条路径相互独立，循环 empymod 主场比较已排除；
- Lei 无 IP 的 SimPEG 和 FEniCSx 门通过；
- Song no-IP、IP 总场和 `delta_IP` 门全部通过；
- Cole-Cole/Prony 材料门、`M=0` 退化门和 Debye 初态门通过；
- 两套数值路径均完成空间、时间和边界三层收敛；
- `Ex/Hz/dBzdt`、零交叉、符号、单位和全部时间道可追溯；
- 论文数字化证据与计算结果没有未解释的趋势、数量级或反号冲突；
- 所有配置、日志、失败记录、环境和校验和均完整保存；
- 报告明确写成“内部数值验证”，不扩大为现场或工程验证。

若最终不能达到门槛，交付物必须是可复现的失败边界、已排除原因和剩余根因，而不是人为制造的通过结论。
