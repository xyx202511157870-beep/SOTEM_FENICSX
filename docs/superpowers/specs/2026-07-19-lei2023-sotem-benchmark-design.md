# Lei 2023 均匀半空间 SOTEM 三求解器验证设计

## 1. 目标与结论边界

本工作建立一个可复现、非循环的电性源瞬变电磁（SOTEM）均匀半空间基准，用于比较以下三条相互独立的正演路径：

1. `empymod` 有限长接地电偶极子的层状介质半解析响应；
2. SimPEG 三维有限体积总场响应；
3. FEniCSx/DOLFINx 三维 Nédélec 边元时域总场响应。

主要目标是验证并调试 FEniCSx 的 `Ex` 与 `dBz/dt`。在该基准通过以前，不把含 IP、复杂地形或三维异常体的结果表述为“已验证”。本基准只能支持代码间一致性和内部数值验证，不能代替工程或实测验证。

## 2. 文献依据

主基准采用 Lei 等（2023）的公开模型：

- Lei et al., *Shadow effect and source overprint effect of short-offset transient electromagnetic method*, Journal of Geophysics and Engineering, 20(2), 439-454.
- DOI: [10.1093/jge/gxad020](https://doi.org/10.1093/jge/gxad020)
- 论文全文：[Oxford Academic](https://academic.oup.com/jge/article/20/2/439/7083017)

论文给出的验证模型为 `100 Ω·m` 均匀半空间、`1000 m` 接地线源、`1 A` 电流、接收点 `(0, 800, 0) m`，比较 `Ex` 和 `dBz/dt`。论文采用电场旋度-旋度方程、切向电场 Dirichlet 外边界、后向欧拉时间离散和 Whitney/Nédélec 边元；文中报告各时间道相对误差小于 `4%`。其局部主计算域为约 `2 km × 2 km × 1.5 km`，远边界扩展到约 `100 km`，网格约 `1,151,863` 个四面体。

论文没有提供可直接读取的逐时间道数值表。因此，论文曲线和 `<4%` 只能作为外部背景证据；本项目的可计算定量基准以独立的 `empymod` 和经过收敛验证的 SimPEG 结果为准。若后续数字化论文图片，必须保存原图、坐标标定和数字化误差，不得把人工读图值冒充作者原始数据。

## 3. 规范模型

### 3.1 用户侧坐标与材料

所有基准配置、CSV 和报告统一使用 `z_down` 坐标：

- `x`：线源正向；
- `y`：水平横向；
- `z = 0`：地表；
- `z > 0`：地下；
- `z < 0`：空气。

材料参数：

| 区域 | 电阻率 | 电导率 | 磁导率 | 极化 |
|---|---:|---:|---:|---|
| 地下均匀半空间 | `100 Ω·m` | `0.01 S/m` | `μ0` | 无 IP |
| 数值空气层 | `1e8 Ω·m` | `1e-8 S/m` | `μ0` | 无 IP |

采用准静态近似，不把位移电流纳入本次验收范围。`1e8 Ω·m` 是数值空气近似，不是文献中的新物性假设；它必须在 SimPEG 与 FEniCSx 中保持一致，并通过空气电阻率敏感性检查确认不控制结果。

### 3.2 源、接收点和波形

为保持与论文的平移等价性，线源居中表示：

| 项目 | `z_down` 规范值 |
|---|---|
| A 电极 | `(-500, 0, +0.1) m` |
| B 电极 | `(+500, 0, +0.1) m` |
| 电流方向 | A 到 B，即 `+x` |
| 通电电流 | `1 A` |
| 接收点 | `(0, 800, +0.1) m` |
| 关断 | `t = 0` 理想阶跃关断 |

论文几何位于 `z = 0`。当前三维离散器需要源和接收点位于地下单元内部，因此规范数值几何下移 `0.1 m`。先前的只读 `empymod` 灵敏度检查表明，相对 `z = 0`，该下移在最早 `10 μs` 处对 `Ex` 和 `dBz/dt` 的影响均小于 `1%`，更晚时间更小。最终报告仍须保存正式的 `z = 0` 对 `z = 0.1 m` 复算结果。

关断前状态是 `1 A` 直流稳态；`t = 0` 后外加源为零。规范基准不得用有限斜坡关断替代理想阶跃后再与阶跃参考直接比较。若当前 FEniCSx 接口只能表达有限斜坡，应增加显式的阶跃基准模式；有限斜坡只能作为单独的波形敏感性实验。

### 3.3 求解器内部坐标映射

| 求解器 | 内部坐标约定 | 规范点的映射 |
|---|---|---|
| empymod | `z` 向下 | 原样使用 `z_down` |
| SimPEG | `z` 向上 | `z_up = -z_down` |
| FEniCSx 当前管线 | `z` 向上 | `z_up = -z_down` |

转换只能发生在各适配器入口。输出必须转换回 `z_down` 规范，并在清单中记录坐标约定、源端点顺序和分量正方向。

## 4. 输出量、单位与时间道

规范输出时间为 `1e-5 s` 到 `1e-1 s` 的 `41` 个以 10 为底等对数时间道，并显式包含或插值输出 `0.1 ms`、`1 ms`、`10 ms`、`50 ms`。

验收分量：

- `Ex`，单位 `V/m`，保留符号；
- `dBz/dt`，单位 `T/s`，保留符号。

诊断分量：

- `Hz`，单位 `A/m`，用于检查 `Bz = μ0 Hz` 和 Faraday 定律的一致性，但不代替两个主验收分量。

禁止对任一求解器进行经验幅值缩放、符号翻转拟合、分量专属校准或时间轴拉伸。任何合法的单位或坐标转换必须在代码和结果清单中明确记录，并有单元测试覆盖。

## 5. 三条独立计算路径

### 5.1 empymod 半解析参考

使用有限长 bipole，不用点偶极子替代 `1000 m` 线源。分别计算电接收器 `Ex` 和磁接收器的 `dBz/dt`，采用相同源端点、接收点、阶跃关断和地下电阻率。空气由层状半空间边界条件处理；另做 `0.1 m` 埋深敏感性结果。

### 5.2 SimPEG 三维有限体积

使用 `LineCurrent`、电场型时域模拟、`PointElectricField` 与 `PointMagneticFluxTimeDerivative`。SimPEG 必须独立完成初始场、源离散、时间推进和接收器投影，不得读取 empymod 数值作为源场或校正量。

### 5.3 FEniCSx Nédélec 边元

使用与论文一致的电场旋度-旋度准静态方程和 Nédélec 边元。关断前 DC 初场、线源投影、材料系数、边界处理、时间推进和接收器投影都由 FEniCSx 路径独立完成。`dBz/dt` 优先由 Faraday 定律的空间旋度获得，并与由磁场时间变化得到的诊断值交叉检查。

允许在后续性能版本中使用主场-二次场分解，但物理验收必须比较重建后的总场，并提供独立总场或半解析参考。均匀背景下“二次场等于零”只能验证分解和数据管道，不能证明总场求解正确。

## 6. 当前已知验证缺口

现有 `corrected_model_runner` 的均匀、无 IP 路径会选择零二次场投影器，而参考路径又使用同一个 empymod 主场。因此其零误差结果本质是“empymod 主场 + 0”与同一 empymod 主场比较，只能标记为 plumbing/管道测试，必须从物理验收汇总中排除。

此前完整时间窗的 FEniCSx 运行曾出现 `Ex` 最大误差远大于 `100%`、`dBz/dt` 最大误差约 `80%`，而短早期 smoke 结果明显更好。该现象是本轮要定位的失败证据，不能通过更改阈值、删除时间道、平滑曲线或覆盖旧报告来消除。

## 7. 误差指标和验收门槛

对每个带符号分量 `u`，以参考曲线在完整时间窗的峰值

`U_peak = max_t |u_ref(t)|`

定义逐道稳健相对误差

`e_robust(t) = |u(t) - u_ref(t)| / max(|u_ref(t)|, 0.01 U_peak)`。

该分母下限用于避免零点附近的相对误差奇异，不会删除任何时间道。另对 `|u_ref| >= 0.01 U_peak` 的强响应道报告传统相对误差；弱响应道报告相对峰值的绝对误差。所有图表必须显示原始带符号曲线和残差。

按以下顺序验收：

1. **不变量门**：单位、坐标、端点顺序、电流方向、波形和分量符号测试全部通过。
2. **SimPEG 独立门**：空间、时间和边界均收敛后，SimPEG 相对 empymod 的两个主分量 `max(e_robust) <= 3%`。
3. **FEniCSx 收敛门**：FEniCSx 的空间、时间和边界逐级变化在强响应道均不超过 `2%`。
4. **FEniCSx 物理门**：FEniCSx 相对 empymod、以及相对收敛 SimPEG 的两个主分量，完整时间窗 `max(e_robust) <= 5%`。
5. **文献复现目标**：在可与论文图对应的时间道上争取达到论文报告的 `<4%`；没有作者数值表时，不把这一项伪装成精确逐点复现。

任何一项失败都保留原始 CSV、配置、日志和失败报告。门槛固定在运行前，不允许根据结果回调。

## 8. 收敛设计

收敛测试采用“一次只改变一个数值因素”的三层序列，并在最终组合上复核。避免直接做全部 `3 × 3 × 3` 笛卡尔积。

### 8.1 空间层级

局部目标特征尺度：

| 层级 | 线源附近 | 接收点附近 |
|---|---:|---:|
| S0 粗 | `40 m` | `20 m` |
| S1 中 | `20 m` | `10 m` |
| S2 细 | `10 m` | `5 m` |

SimPEG 使用独立构造的有限体积网格，FEniCSx 使用独立构造的四面体网格；二者只共享物理几何，不共享离散权重。远离源和接收点允许平滑几何加粗，但必须记录最小/最大单元、单元数、自由度数和网格生成参数。

### 8.2 时间层级

在固定 `41` 个输出道之间使用后向欧拉子步进：

| 层级 | 每个输出区间的最少子步数 |
|---|---:|
| T0 | `1` |
| T1 | `2` |
| T2 | `4` |

初始 `0 -> 10 μs` 区间也必须按同一规则细分。若求解器使用等价的自适应步进，必须输出实际步长并证明其误差不大于对应固定层级。

### 8.3 边界层级

保持论文约 `2 km × 2 km × 1.5 km` 的局部精细区域，使用分级粗化把外边界扩展至：

| 层级 | 最大远边界尺度 |
|---|---:|
| B0 | `25 km` |
| B1 | `50 km` |
| B2 | `100 km` |

这里的尺度指从源区到最远人工边界的量级；各方向的实际坐标必须写入配置。若使用海绵层或阻抗边界，需与纯远边界方案分开报告，不能把吸收参数拟合到参考曲线。

### 8.4 资源控制

先完成 empymod 与 SimPEG 的 S/T/B 单轴收敛，再进行 FEniCSx 粗、中层级诊断。只有符号、波形和初场正确后才启动 S2/B2 的高成本计算。所有重计算在 WSL2 的 `/home/paidaxin/miniconda3/envs/fenicsx` 环境中运行；记录峰值内存和运行时间，结束后关闭不再需要的 WSL 实例。

## 9. 调试顺序

FEniCSx 未通过时按以下顺序定位，每一步都用最小失败用例和自动测试固定结论：

1. 坐标转换、源端点顺序、电流幅值、单位和接收分量符号；
2. 理想阶跃关断的定义及 `t = 0-` DC 初场；
3. 线源在 Nédélec 自由度上的投影和总注入电流；
4. 接收点定位、边元插值和 `Ex` 分量提取；
5. `curl(E)`、`dBz/dt` 符号及 `μ0` 因子；
6. 弱式中的 `σ`、`μ^-1` 系数和后向欧拉矩阵；
7. 时间步长、边界距离、空气电阻率和局部网格敏感性；
8. 仅在上述项目通过后检查线性求解器容差和性能优化。

不通过“试一个比例因子直到曲线重合”的方式调试。

## 10. 可复现产物

实现阶段应增加一个版本控制内的基准目录，至少包含：

- 单一规范模型配置和 JSON Schema/校验器；
- 三个求解器的显式适配器；
- 坐标、单位、波形和源强不变量测试；
- 三层收敛配置；
- 统一的带符号 CSV 字段定义；
- 比较、绘图和验收报告生成器；
- 机器可读的 `manifest.json`，记录提交、环境、配置哈希和结果文件哈希。

建议生成目录结构：

```text
generated/lei2023_homogeneous_halfspace/<run-id>/
  manifest.json
  model.json
  empymod.csv
  simpeg_S*_T*_B*.csv
  fenicsx_S*_T*_B*.csv
  convergence.json
  comparison.csv
  report.md
  figures/
  logs/
```

`generated/` 保持不入 Git；小型黄金数据、配置、测试和失败摘要可以入库。旧失败产物不得被同名覆盖，每次运行使用唯一 `run-id`。

## 11. 完成定义

只有同时满足以下条件，才能声明“FEniCSx 均匀半空间内部数值验证通过”：

- 三条路径确实独立，循环 empymod 主场比较已从物理验收中排除；
- SimPEG 先通过相对 empymod 的 `3%` 门槛；
- FEniCSx 完成三层空间、时间和边界收敛；
- FEniCSx 的 `Ex` 与 `dBz/dt` 在完整时间窗相对两个独立参考均通过 `5%` 门槛；
- 所有时间道、符号、配置、日志、失败记录和环境信息均可追溯；
- 报告明确写成“内部数值验证”，不扩大为现场或工程验证。

若最终不能达到门槛，交付物应是可复现的失败边界、已排除原因和剩余根因，而不是人为制造的通过结论。
