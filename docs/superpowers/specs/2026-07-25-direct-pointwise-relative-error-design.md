# Zhou TEM-IP 直接逐时间道相对误差评价设计

日期：2026-07-25  
状态：用户已确认评价原则，等待书面设计复核

## 1. 目标

统一正式 S1T1B1 模型和强 IP 扩展模型的 FEniCSx–empymod 误差评价方式，使主误差曲线符合地球物理电磁正演论文的常见做法，并避免用全曲线相对 L2 掩盖局部时间道误差。

本次只重新计算误差、重绘图片和更新 Word/JSON，不重新运行 FEniCSx 或 empymod 正演。

## 2. 文献依据

GJI 的三维电磁有限元验证工作将相对误差定义为：

\[
\mathrm{RE}_i(\%)=
100\left|
\frac{F_i-E_i}{E_i}
\right|,
\]

并将绝对响应和逐点相对误差共同绘制。该文同时说明，参考解过零附近的相对误差可能达到几十个百分点，需要结合整体响应解释：

- https://academic.oup.com/gji/article/204/3/1550/678228

三维 EM-IP 正演验证工作同样逐时间道评价相对误差，并将反号区误差与其他时间道分开解释：

- https://academic.oup.com/gji/advance-article/doi/10.1093/gji/ggaf462/8323168

## 3. 主误差曲线

对每个分量、工况和时间道，定义：

\[
\boxed{
\mathrm{RE}_i(\%)=
100\frac{|F_i-E_i|}{|E_i|}
}
\]

其中：

- \(F_i\)：FEniCSx 响应；
- \(E_i\)：empymod 参考响应；
- 分量包括 \(E_x\)、\(H_z\) 和 \(\partial B_z/\partial t\)；
- 工况包括 no-IP、正式 IP 和强 IP。

主误差曲线不再使用

\[
\max(|E_i|,10^{-6}\max|E|)
\]

替换分母。

### 3.1 零值和过零点处理

- 若 \(E_i=0\)，普通相对误差数学上未定义，数据记为 `NaN`，JSON 中写为 `null`，图中留空。
- 若 \(E_i\ne0\) 但非常接近零，仍按原始公式计算并保留误差尖峰，不平滑、不截断、不设置显示上限来隐藏尖峰。
- 使用仅由 empymod 决定的诊断标记识别过零敏感区：
  - 相邻参考样点发生符号变化；或
  - \(|E_i|<10^{-6}\max_j|E_j|\)。
- 上述 \(10^{-6}\) 只用于标记和分区统计，不参与主误差公式的分母。

## 4. 验收逻辑

### 4.1 普通有效时间道

在非过零敏感时间道内：

- \(\mathrm{RE}_i\le5\%\)：吻合良好；
- \(5\%<\mathrm{RE}_i\le10\%\)：警告，需要解释；
- 连续多个有效时间道 \(\mathrm{RE}_i>10\%\)：该分量/工况不能判定通过。

JSON 和 Word 至少报告：

- 有效时间道数量；
- \(\le5\%\)、\(5\%-10\%\)、\(>10\%\) 的时间道数量；
- 普通有效时间道最大误差及对应时间；
- 过零敏感时间道数量。

### 4.2 过零敏感区

过零敏感区不因相对误差尖峰自动判定算法失败，但必须：

- 保留原始误差尖峰；
- 绘制有符号 FEniCSx 和 empymod 响应；
- 报告两者反号时间或最近零点时间；
- 报告绝对误差；
- 不将其混入“普通有效时间道均低于 5%”的结论。

### 4.3 辅助总体指标

保留全曲线相对 L2：

\[
\mathrm{RE}_{L2}=
100\frac{\|\mathbf F-\mathbf E\|_2}{\|\mathbf E\|_2}.
\]

相对 L2 只作为总体汇总，不单独决定算法是否通过。

## 6. JSON 和 Word

### 6.1 JSON

每个分量和工况保存：

- `pointwise_absolute_relative_error_percent`；
- `undefined_reference_zero_mask`；
- `zero_crossing_sensitive_mask`；
- `ordinary_gate_counts`；
- `ordinary_max_error_percent`；
- `ordinary_worst_time_s`；
- `relative_l2_percent`；
- 明确的公式字符串。

移除把 floor 误差描述为主误差的字段；如为追溯保留旧统计，必须标记为 `legacy_diagnostic`，不得用于正式结论。

### 6.2 Word

Word 中明确写明：

- 主误差曲线为直接逐时间道绝对相对百分误差；
- 过零点附近可能出现大误差尖峰；
- 相对 L2 是辅助指标；
- 最终结论由普通有效时间道误差、过零诊断、有符号响应、L2 和收敛证据共同形成。

不得用小 L2 值把严格逐时间道失败改写为通过。

## 7. 测试与验收

实施前先增加失败测试，至少覆盖：

1. 普通非零参考值严格使用 \(100|F-E|/|E|\)；
2. 负参考值使用其绝对值作分母；
3. 参考值严格为零时输出 `NaN`/`null`；
4. 近零但非零参考值保留真实大误差，不使用 floor；
5. 过零敏感区标记不改变误差数值；
6. 正式模型和强 IP 模型采用同一实现；
7. Word 的公式、图注和统计字段与 JSON 一致。
