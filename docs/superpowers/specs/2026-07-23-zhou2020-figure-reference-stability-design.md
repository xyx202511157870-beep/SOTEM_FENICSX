# Zhou 2020 响应图与弱 IP 参考稳定性修订设计

日期：2026-07-23
状态：用户已于 2026-07-23 确认
范围：严格验证图、相关指标解释和 Word 报告；不重新求解正式 FEniCSx 场，不生成 PDF

## 1. 修订目标

当前验证报告混用了两种目的不同的图：

1. 文献式响应曲线，用于比较响应幅值随时间的总体形态；
2. 有符号诊断曲线，用于检查反号、伪反号和零点。

文献采用双对数绝对值曲线，而当前主图使用 `symlog`，导致负值以带负号的对数刻度出现。此外，当前 `dBz/dt` 独立 IP 增量由两个很强的 empymod 时域总场直接相减得到，早期弱差分对频—时变换高度敏感，出现非物理锯齿。

本次修订的核心结论是：

> 文献复现主图必须使用 `log10(|response|)`；反号只在独立有符号诊断中审计。默认 DLF 的早期 `dBz/dt` 弱 IP 锯齿属于参考变换不稳定性，不能作为物理响应或严格误差证据。

## 2. 已确认的数值证据

正式模型早期 `dBz/dt` 的 IP、no-IP 总场约为

\[
4\times10^{-7}\ \mathrm{T/s},
\]

而 IP 增量只有

\[
10^{-14}\sim10^{-10}\ \mathrm{T/s}.
\]

诊断结果如下：

- 默认 DLF 的前 20 个 `dBz/dt` 增量点换号 10 次；
- 频域先作 IP−no-IP、再执行 QWE 变换后，早期值降至约
  \(10^{-14}\sim10^{-13}\ \mathrm{T/s}\)；
- 默认 DLF 与频域差分 QWE 的主峰均约为
  \(1.7622\times10^{-9}\ \mathrm{T/s}\)；
- 两者全窗相对 L2 差异约 6.44%，前 20 点差异约 93.65%；
- 依据多种变换结果的点对点离散度，`dBz/dt` 增量从约
  \(5.77\times10^{-4}\ \mathrm{s}\) 起才形成至少 5 个连续的稳定样点；
- FEniCSx 相对频域差分 QWE 的 `dBz/dt` 增量全窗相对 L2 约 9.44%，
  稳定时间窗内约 9.39%；
- QWE 的全局收敛布尔值仍为 `False`，因此 9.44% 只能作为敏感性结果，
  不能升级为正式通过证据。

## 4. 指标与判定规则

### 4.1 保留的正式判定

- IP、no-IP 总场的有符号相对 L2；
- `Ex` 首次反号时刻；
- `Hz` 参考解没有反号而 FEniCSx 在约 0.022 s 出现反号；
- 网格、时间步和边界收敛证据。

### 4.2 降级为敏感性结果的指标

原报告中的独立 IP 增量误差：

- `Ex` 16.32%；
- `Hz` 61.26%；
- `dBz/dt` 11.40%。

这些数值仍保留在可复现证据中，但 Word 不再把它们统一称为“严格 IP 增量失败”，原因是 empymod 弱差分本身未通过变换稳定性审计。

修订后的表述为：

- `Ex`、`Hz` 弱 IP 增量：参考稳定性不足，暂不判定；
- `dBz/dt` 弱 IP 增量：默认 DLF 为 11.40%，频域差分 QWE 敏感性结果约
  9.44%，但 QWE 全局收敛标志失败，因此仍为 `inconclusive`；
- 整体算法状态仍不是完全通过，因为 `Hz` 晚期伪反号是独立、明确且不依赖弱差分的失败证据。

## 6. 数据完整性与禁止操作

禁止：

- 仅为了让曲线平滑而删除早期点；
- 对响应曲线进行未声明平滑；
- 取绝对值后宣称反号已通过；
- 根据结果临时放宽阈值；
- 把 `converged=False` 的 QWE 结果包装成严格参考真值；
- 覆盖或删除原失败证据。

允许：

- 主图按文献定义绘制绝对值；
- 在单独诊断图中保留有符号数据；
- 用阴影明确标注参考不稳定区；
- 将不具备稳定参考的数据标记为 `inconclusive`。

## 7. 测试设计

实现前先加入失败测试，覆盖：

1. 文献式主图的 y 轴必须是普通 log，输入必须经过绝对值；
2. 有符号诊断图不得使用 symlog；
3. `dBz/dt` 稳定性审计必须保留全部样点并记录不稳定时间边界；
4. QWE `converged=False` 时，指标状态必须是 `inconclusive`，不能是 `passed`；
5. Debye 图指标必须是 4 项相对 16 项，而不是相对不稳定 empymod 弱差分；
6. Word 必须包含 `reference-transform unstable`、`inconclusive`、
   `0.022 s` 和“绝对值不提供符号信息”等关键说明；
7. 原始严格比较 JSON 不被覆盖。

测试需要在以下两套环境中执行：

- Windows 科学计算环境；
- WSL2 FEniCSx Conda 环境。
