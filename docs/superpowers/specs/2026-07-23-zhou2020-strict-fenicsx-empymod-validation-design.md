# Zhou 2020 接地线源 TEM-IP 严格验证设计

## 1. 目标与结论边界

本工作为当前 FEniCSx 三维时域有限元电性源 TEM-IP 正演器建立一套参数闭合、可复现、可审计的公开基准验证，并形成中文 Word 验证报告。

正式主基准采用：

> Zhou, N.-N., Lei, K., Xue, G., and Chen, W. (2020).
> *Induced Polarization Effect on Grounded-Wire Transient Electromagnetic Data from Transverse Electric and Magnetic Fields*.
> GEOPHYSICS, 85(4), E111-E120.
> DOI: https://doi.org/10.1190/geo2019-0322.1

主基准选择理由：

- 源型与当前程序一致：有限长接地电性源；
- 介质为一维层状模型，可由 empymod 独立计算；
- 论文给出 `Ex` 和 `Hz` 的 IP/no-IP 响应特征；
- 同作者配套技术披露给出层厚、电阻率、极化参数、源长、电流和接收位置；
- `Ex` 具有明显的极化曲线分离和反号，可检验极化记忆项；
- `Hz` 对 IP 变化较弱，可检验普通电磁扩散和初始磁场，而不能单独作为 IP 正确性的证据。

Song 2025 模型从正式定量验收中移除，仅保留为三维 SOTEM-IP 定性补充。原因是当前可获得资料没有把极化体全部尺寸、位置、接收坐标、波形和曲线数值形成可逐项追溯的完整参数闭环。不得用仓库中假定的 Song 参数替代文献参数后再宣称“复现 Song 文献”。

本验证通过后，只允许声明：

> FEniCSx 接地线源 TEM-IP 正演器在指定一维层状公开基准、规定时间窗和规定误差指标下通过内部数值验证。

不得扩展为：

- 已通过堤坝现场验证；
- 已证明任意三维极化体都正确；
- 已证明真实仪器波形、线圈和噪声模型正确；
- 已证明工程探测深度或渗流通道可探测性。

## 3. 规范模型

### 3.1 公共坐标

所有配置、CSV、图件和报告采用右手坐标系：

- `x`：发射线方向；
- `y`：水平横向；
- `z_down`：向下为正；
- 地表：`z_down = 0`。

规范化源与接收几何：

| 项目 | 规范值 |
|---|---:|
| A 电极 | `(-500, 0, 0) m` |
| B 电极 | `(+500, 0, 0) m` |
| 电流方向 | A 到 B，即 `+x` |
| 稳态电流 | `10 A` |
| 接收点 | `(0, 1000, 0) m` |
| 关断 | `t=0` 理想 step-off |

该坐标由技术披露中的 `(0,0)` 至 `(1000,0)` 发射线和 `(500,1000)` 接收点整体平移 `(-500,0)` 得到。坐标平移不改变层状介质响应，但该推导必须写入 manifest 和报告。

FEniCSx 内部若使用 `z_up`，只允许在适配器边界转换：

`z_up = -z_down`

输出必须转回规范坐标，并记录每个磁场分量的正方向。

文献规范位置保持在地表 `z_down=0`。若 FEniCSx 的点定位、边界自由度或源正则化要求把源/接收点轻微下移，不得静默把下移后的几何当作文献原值。应当：

- empymod 同时计算 `z_down=0` 的规范参考和对应下移位置的数值敏感性参考；
- FEniCSx 候选下移量采用 `0.05 m`、`0.1 m`、`0.2 m`；
- 报告下移造成的响应变化；
- 只在变化进入稳定平台且不影响验收结论时选择一个数值位置；
- 不得用下移量拟合幅值或反号时间。

FEniCSx 所需空气层和非零空气电导率属于数值实现参数，不属于文献地质参数。空气高度、侧向范围和空气电导率必须进入边界/空气敏感性试验并写入 manifest，不能根据参考曲线调节。

总场定义必须包含规范接地源所对应的源电流和地下回流电流。若当前实现把地表供电导线磁场、地下传导电流磁场或电极贡献分开计算，必须保存各分量和闭合误差，禁止遗漏或重复计入。

### 3.2 三层电性模型

| 层 | `z_down` 范围 | DC 电阻率 | 厚度 | 极化 |
|---|---:|---:|---:|---|
| 1 | `0-500 m` | `100 ohm m` | `500 m` | 无 |
| 2 | `500-520 m` | `10 ohm m` | `20 m` | 有 |
| 3 | `>520 m` | `200 ohm m` | 半空间 | 无 |

第二层极化参数：

- 充电率 `m = 0.1`；
- 时间常数 `tau = 1 s`；
- 频率指数 `c = 0.3`。

第二层只有 `20 m` 厚。正式 FEniCSx 网格必须使该层至少被 4 个垂向单元解析，生产级候选采用 `5 m` 和 `2.5 m` 两级界面分辨率比较；不能让材料界面切过未标记的粗单元后仍宣称复现薄层。

### 3.3 Cole-Cole 约定

主基准采用 Pelton 复电阻率形式：

`rho*(omega) = rho0 * [1 - m * (1 - 1/(1 + (i*omega*tau)^c))]`

其中 `rho0` 是零频/DC 电阻率。因此第二层：

- `rho0 = 10 ohm m`；
- `sigma0 = 1/rho0 = 0.1 S/m`；
- `rho_inf = rho0*(1-m) = 9 ohm m`；
- `sigma_inf = 1/rho_inf = 0.111111111111... S/m`。

不得把 `10 ohm m` 当作高频电阻率，也不得直接以 `delta_sigma = m*sigma_inf` 代替一般 `c<1` 的 Pelton 复电阻率。

empymod 参考路径直接使用精确复电阻率或其倒数复电导率。FEniCSx 的时域记忆变量路径使用非负广义 Debye/Prony 展开逼近同一个目标复电导率。

Debye 拟合必须：

- 在运行前固定频带、极点数和权重；
- 频带覆盖全部仿真时间尺度，并在两端保留至少一个数量级余量；
- 强制满足 DC 电导率约束；
- 输出复电导率实部、虚部、幅值和相位误差；
- 不得根据时域响应重新调整极点或幅值；
- 目标频带内复电导率相对 L2 误差不超过 `1%`。

### 3.4 关断前初始状态

理想 step-off 在 `t<0` 已长时间通电。初始 DC 场必须使用 `sigma0`：

`-div(sigma0 grad(phi0)) = qA - qB`

`E0 = -grad(phi0)`

极化记忆状态必须处于 DC 稳态，不能统一置零。每个 Debye 状态的初值由采用的状态变量定义解析得到，并通过以下退化测试：

1. `m -> 0` 连续退化到完全相同的 no-IP 系统；
2. 长时间恒定电场下，总电流收敛到 `sigma0 E0`；
3. 瞬时高频极限与 `sigma_inf` 一致；
4. 初始状态不读取 empymod 时间响应或文献曲线。

## 4. 三条证据路径

### 4.1 empymod 独立层状参考

empymod 是正式定量参考，使用有限长 bipole，而不是点偶极近似。

必须完成：

- no-IP 三层模型；
- 精确 Pelton Cole-Cole IP 三层模型；
- `Ex`、`Hz` 和 `dBz/dt`；
- 有符号输出及单位；
- 源积分点数收敛，例如 `srcpts = 3, 5, 9, 17`；
- 数字滤波器、Hankel/Fourier 参数和 empymod 版本记录。

`Hz` 输出单位为 `A/m`；`Bz = mu0*Hz`；`dBz/dt` 为 `T/s`。任何换算都必须显式保存，禁止混用 `Hz` 名称与 `nT` 数值。

### 4.2 FEniCSx 三维有限元

FEniCSx 独立完成：

- 三维网格与材料标记；
- 接地电极 DC 初始场；
- Nedelec `H(curl)` 电场离散；
- 有限线源或与接地电极一致的源处理；
- 后向欧拉时间推进；
- Debye/Prony 极化状态更新；
- `Ex` 点/有限电偶极接收；
- `Hz` 初始场与 Faraday 推进；
- `dBz/dt = -curl(E)_z` 接收；
- 边界条件和线性求解。

FEniCSx 不得加载 empymod 响应作为初始场、主场、校正常数或缩放因子。empymod 只允许在求解完成后进入比较器。

### 4.3 文献响应图

期刊原图只作为外部复现证据。对原图进行数字化时必须保存：

- 原始截图或合法获取的页面渲染；
- 图号和图注；
- x/y 轴范围、对数或线性标度；
- 曲线标签、颜色和线型；
- 数字化点；
- 数字化日期和工具；
- 图像分辨率；
- 估计数字化不确定度。

文献曲线没有作者原始数据时，不设置伪精确的逐点 `5%` 门槛。文献图比较只验收：

- 数量级；
- 衰减趋势；
- IP/no-IP 开始明显分离的时间尺度；
- `Ex` 反号次数与反号时间；
- `Hz` 的 IP/no-IP 差异是否保持很弱。

文献描述的预期特征为：

- `Ex` 的 IP/no-IP 曲线约从 `1e-2 s` 开始明显分离；
- `Ex` 约在 `1e-1 s` 附近发生符号反转；
- `Hz` 的 IP/no-IP 曲线基本重合，仅有较小差异。

## 5. 时间窗和波形

第一版正式输出时间道：

`1e-4 s` 至 `3 s`，共 `101` 个等对数时间道。

理由：

- 覆盖普通电磁扩散早期；
- 覆盖 `1e-2 s` 左右的曲线分离；
- 覆盖 `1e-1 s` 左右的反号；
- 覆盖 `tau=1 s` 的主要极化衰减尾部。

内部求解时间步独立于输出时间道。至少采用三档：

| 级别 | 每个相邻输出道最少子步数 |
|---|---:|
| T0 | 1 |
| T1 | 2 |
| T2 | 4 |

`0` 到第一个输出时间之间也按同等细化规则处理。所有求解均使用理想 step-off；真实有限关断波形不进入本基准。

若生产级 FEniCSx 在 `3 s` 全窗计算成本不可接受，只允许把运行状态标记为“分阶段未完成”，不得把截止到 `1 ms` 或 `0.1 s` 的结果写成全窗验证通过。

## 6. 验收指标

### 6.1 有符号总场

对任意参考分量 `u_ref(t)`：

`U_peak = max_t |u_ref(t)|`

稳健逐时刻误差：

`e_robust(t) = |u(t)-u_ref(t)| / max(|u_ref(t)|, 0.01*U_peak)`

另报告：

- 全时窗相对 L2；
- 峰值相对误差；
- 最大绝对误差；
- 最大稳健误差及所在时间；
- 强响应道 `|u_ref| >= 0.01 U_peak` 的普通相对误差；
- 弱响应道相对参考峰值的绝对误差。

不得删除零点附近数据，也不得用普通相对误差在零点附近制造无意义的大百分比。

### 6.2 纯极化增量

对每个分量计算：

`delta_IP(t) = u_IP(t) - u_noIP(t)`

使用 `delta_IP` 自身峰值作为分母尺度，报告：

- 相对 L2；
- 最大峰值归一化绝对误差；
- 强极化响应道误差；
- 极化效应比 `u_IP/u_noIP - 1`，仅在 no-IP 分母高于门限时报告。

### 6.3 零交叉

零交叉以相邻非零带符号样本异号定义，并在对数时间上插值。报告：

- 零交叉数量；
- 第一次零交叉时间；
- empymod、FEniCSx 和文献数字化结果；
- FEniCSx 相对 empymod 的零交叉时间误差；
- 文献数字化不确定度。

验收门槛：

- FEniCSx 与 empymod 的零交叉数量一致；
- 第一次零交叉时间相对差不超过 `10%`；
- 文献比较只要求落在数字化不确定度和一个相邻图示采样间隔允许的范围内。

### 6.4 固定门槛

在运行前固定以下内部验收门槛：

1. Debye 复电导率拟合相对 L2：`<=1%`；
2. no-IP `Ex/Hz/dBzdt` 全时窗相对 L2：`<=5%`；
3. IP 总场 `Ex/Hz/dBzdt` 全时窗相对 L2：`<=5%`；
4. 强 `delta_IP` 响应相对 L2：`<=10%`；
5. 时间、网格、边界相邻细化级的强响应道变化：`<=2%`；
6. 第一次零交叉时间差：`<=10%`。

门槛不得在看到结果后放宽。若单个分量失败，报告必须保留失败状态、原始数值和最差时间道。

## 7. 收敛和独立性审计

正式验证至少包含：

### 7.1 empymod 源积分收敛

有限线源 `srcpts` 逐级增加。相邻两级在所有正式分量强响应道上的变化应不超过 `0.5%`，否则继续增加积分点。

### 7.2 FEniCSx 空间收敛

至少三档空间模型：

- S0：薄层垂向约 `10 m`，仅用于粗筛；
- S1：薄层垂向 `5 m`；
- S2：薄层垂向 `2.5 m`。

源、接收点和层界面同时局部加密。每档保存：

- 单元数、自由度数；
- 最小/最大单元尺度；
- 薄层实际单元数；
- 材料界面一致性检查；
- 网格质量统计；
- 峰值内存和运行时间。

### 7.3 时间收敛

使用 T0/T1/T2。比较必须在同一输出时间道插值或直接取值，不得通过平滑改变曲线。

### 7.4 边界收敛

至少三档远边界或等价的已验证边界方案。每档必须记录实际模型范围和边界条件。边界大小不能根据参考曲线调幅。

### 7.5 初始磁场和 Faraday 一致性

保存：

- `H0/B0` 的计算方法和各贡献；
- 初始场求积/磁静态恢复收敛；
- `B(t)` 推进与 `-curl(E)` 的离散 Faraday 残差；
- `Hz` 与 `dBz/dt` 的 `mu0` 和符号审计。

### 7.6 求解器独立性

验证运行记录线性求解器、预条件器、容差、迭代数和残差。至少选一个代表模型用更严格容差复算，确认正式响应不受原容差控制。

## 8. 执行门和失败处理

严格按以下顺序推进：

1. 参数来源和坐标合同检查；
2. empymod no-IP 与精确 Cole-Cole IP 参考；
3. Debye 拟合门；
4. FEniCSx no-IP 粗模型；
5. no-IP 通过后启用极化；
6. FEniCSx IP 粗模型；
7. 符号、单位、反号和数量级通过后运行收敛序列；
8. 生产级全窗运行；
9. 文献曲线数字化与外部趋势比较；
10. 生成 Word。

任一前置门失败：

- 停止依赖该门的高成本运行；
- 保留配置、日志、CSV、图件、异常和软件版本；
- 不覆盖旧 run-id；
- 记录最小复现实验和下一项根因检查；
- 状态标记为 `failed_with_reproducible_evidence`。

允许的顶层状态：

- `parameter_contract_verified`；
- `reference_verified`；
- `noip_internally_validated`；
- `ip_internally_validated`；
- `failed_with_reproducible_evidence`；
- `incomplete_time_window`。

禁止使用 `passed` 这一模糊状态掩盖只通过部分时间窗或部分分量。

## 11. 非本轮范围

本轮不包括：

- Song 三维极化体的正式定量复现；
- 堤坝、库水、坝基和真实渗流通道模型；
- 真实线圈面积、匝数、传递函数和噪声；
- 现场数据；
- SimPEG 作为第三条正式 IP 路径；
- GJI 2025 中闭合回线 `dBz/dt` 基准的实现。

GJI 2025 闭合回线基准可作为后续独立磁极化验证，但当前接地源/DC 初始场管线不能在没有额外设计的情况下把它混入主验证。
