# 渗流通道三算法当前状态

更新日期：2026-07-18

## 当前保留模型

- 发射源：100 m 接地平行导线。
- 异常体：导线正下方、埋深约 20 m 的长方体渗流通道。
- 接收器：删除位于导线上的不稳定观测点后，保留其余接收点。
- 坐标与绘图：地表为 `z=0`，地下为 `z>0`，空气为 `z<0`；三维模型图按 Z 轴向下显示。
- FEniCSx 几何：完整三维全域求解，不采用只求一侧再镜像的做法。

## 三个求解器的职责

- SimPEG：三维背景与含异常体模型的主参考计算。
- FEniCSx：独立完整三维有限元计算，用于检查异常体响应和空间离散敏感性。
- empymod：分层均匀背景参考。它不代表三维渗流异常体解，不能单独证明异常体计算正确。

## 已获得的证据

均匀半空间以及早期强信号时间窗内，三个求解路径具有较好一致性。当前强信号掩码大致只覆盖到 `6.31e-5 s`，因此该结果主要证明背景场和早期响应实现没有明显量纲或波形错误。

## 尚未通过的验证

晚期 Ex 未通过空间收敛验证。约从 `3.98e-3 s` 开始，FEniCSx 与 SimPEG 的异常体差异响应出现明显分离；在 `1e-2 s` 附近，Rx4 甚至发生符号差异。现有时间步敏感性结果相对稳定，但空间网格序列和接收器恢复方式仍能改变晚期尾部及符号。

因此当前结果只能标记为“计算进展已保存，晚期异常体响应待修复”，不能标记为完整内部验证通过，也不能用均匀半空间的小误差替代异常体模型验证。

## 后续修复入口

1. 固定相同几何、边界、源和接收器算子，建立不少于三档的局部空间加密序列。
2. 对 Rx4/Rx5 的 `Ex` 同时输出单元值、局部最小二乘恢复值和邻域统计值，定位符号翻转来源。
3. 对异常响应 `channel - background` 单独检查绝对误差、符号和收敛阶，避免相对误差被接近零的晚期信号放大。
4. 只有空间序列给出稳定极限后，才重新生成“验证通过”的 Word 报告。
